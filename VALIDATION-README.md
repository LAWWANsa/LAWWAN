# LAWWAN Validation MVP

This build is for early market validation before the commercial launch.

- Public trainer-interest form: `/become-trainer`
- How the platform works: `/how-it-works`
- Trainer discovery: `/trainers`
- All demo trainers, names, schedules and prices are fictional/demo data.
- The trainer-interest form stores submissions in Supabase table `trainer_interest_leads`.
- Real payments are not enabled in this validation phase.

The database table and RLS policies for `trainer_interest_leads` were applied separately to the LAWWAN Supabase project.
